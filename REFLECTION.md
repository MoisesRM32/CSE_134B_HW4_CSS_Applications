Reflection 

This assignment was more challenging than I expected because it was not just about making the pages look good. I had to pay attention to the exact directory structure, shared HTML skeleton, relative paths, and the specific layout technique required for each page. One of the biggest problems I ran into was mixing up the root `index.html` with `guide/index.html`. That caused the wrong content and stylesheet paths to appear on the Cheese Guide page. Fixing that helped me understand directory navigation much better.I also learned why separating CSS by purpose matters. At first, I had too many page-specific rules inside `site.css` and `global.css`. It made it harder to understand which rules affected which page. I eventually organized the styles so that `tokens.css` seperated appropriate properties, `global.css` handled resets and typography, `site.css` handled shared elements, and each page type had its own layout stylesheet. This made the project much easier to debug. Another part I found useful was creating interaction without JavaScript. The Cheese Fact popover and the Join dialog both worked using HTML attributes. If I were doing this assignment again, I would first set up the exact file structure, shared navigation, and relative paths before adding content. I would also validate each page as soon as I finished it instead of waiting until the end. That would have saved time and prevented several mistakes from spreading across multiple pages.Overall, this project gave me much more confidence in building a complete multi-page website using only HTML and CSS. Highlighting how important it is to ensure organization between html and css files and being organized throughout multi page web development.
